## 宿題

- 取り組んだレベル：基礎 / 実装 
- やったこと：ask.pyに対し、対話モードを追加し、--interacriveオプションを追加することによって会話履歴を保ったまま追加質問できるようにした。
- 結果：会話履歴の保持のコードは比較的簡単に実装できたものの、ターミナル上でuv run python -m app.ask --interactiveからチャットを起動し、質問文をタイピングした際にエンターを押すと文字をすべて消してもターミナルの表示上に最初の数文字が表示され続ける問題が発生。Copilotを使って処理しようとしたものの、会話履歴の保持よりも実装時間がかかった。なんなら解決しなかった。会話履歴の保持ができることによって、文脈のある会話ができるようになった。（例）質問１：今日は豚肉の気分　→　応答１：どの料理にしますか？　→　質問２：生姜焼きにしようかな　→　応答２：豚と言えば生姜焼きですよね！のような会話。
